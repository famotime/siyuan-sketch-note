# 闲笔 —— 人生，总要有几处闲笔

## v1.0.0
### 新增
- **录制与回放**：支持对画笔操作进行录制与回放；
- **回放增强**：回放控制栏新增「重生」按钮，支持从当前步骤截断历史记录；
- **实时同步**：支持移动端手写实时投屏到 PC 端查看，基于 Broadcast API 实现 writer/viewer 双模式、会话管理、快照恢复与事件流式渲染；
- **矢量数据导出**：导出 PNG/PDF 时自动嵌入矢量笔迹数据，可重新导入恢复编辑；
- **清理无效笔记**：支持检测并清理无效手写笔记数据；

### 改进
- 统一手写与缩略图渲染引擎，实现撤销重做录像同步；
- 导入笔记时若画布已有内容，弹窗确认是否覆盖；
- 修复非套索工具下图片选中后无法缩放/旋转，拖动时保持控制手柄可见；
- 修复手写回放中橡皮擦和移动操作的回放错误；

## v0.9.0
### 新增
- **画笔系统**：画笔和荧光笔支持切换不同笔型/笔尖，每种笔型拥有独立的压感曲线和透明度效果，新增下拉菜单组件快速切换；
- **从新页签打开**：支持在独立页签中打开手写画布，便于分屏状态下同步阅读和手写；
- **长按拖动**：文本/图形/套索模式下长按可选中并拖动元素，方向键可微调位置；
- **文本框增强**：支持多行输入；
- **添加图片**：支持在画布上添加图片，支持缩放、旋转、透明度设置；
### 改进
- **笔刷优化**：重新调优画笔与荧光笔默认参数，提升书写手感；
- **颜色面板升级**：14 种预置颜色更新为暖彩彩虹渐变色板，底部历史颜色改为收藏栏；
- **形状工具改进**：形状按钮改为下拉选择，默认图形改为矩形；
- **工具栏图标**：各项工具图标替换为更直观易辨的样式；

## v0.8.0
闲笔（siyuan-sketch-note）首个发布版本
在思源笔记文档中嵌入一块手写画布，用触控笔或鼠标自由书写、绘图、标注，内容以矢量形式保存，随时可以再次编辑。

### 典型场景

**课堂 / 会议速记** — 手写比打字更快捕捉灵感。插入一个手写块，用画笔或荧光笔记录要点，支持多页分隔，结束后导出 PDF 存档。

**思路整理** — 用形状工具画流程图，用套索移动和重组内容，用文本框补充说明。9 种内置稿纸模板（方格、横线、康奈尔笔记等）帮助你快速排版。

### 功能一览

| 工具 | 说明 |
|------|------|
| 画笔 | 基础手写工具，支持压感（需硬件支持） |
| 荧光笔 | 半透明标注，适合重点标记 |
| 橡皮擦 | 两种模式：像素擦除（精确）和整笔擦除（快速） |
| 形状 | 直线、箭头、矩形、椭圆、三角形 |
| 文本 | 在画布上添加可编辑文字 |
